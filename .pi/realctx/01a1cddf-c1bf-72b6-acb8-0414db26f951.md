`realtry` (`./src/index.ts`) replaces Pi's internal retry and provider SDK internal retries (`maxRetries: 0`) without injecting synthetic user/custom/error messages into sessions.

- Verification: `npm run check` (`tsc --noEmit && node --test`).
- Defaults (`DEFAULT_SETTINGS`): `stallTimeoutMs: 600_000` (`10m`), `maxRetryDurationMs: 43_200_000` (`12h`), `maxRetries: 0` (`unlimited`), `baseDelayMs: 1_000` (`1s`), `maxDelayMs: 30_000` (`30s`), `retryEmpty: true`, `retryIncomplete: true`.
- Settings: `~/.pi/agent/extensions/realtry.json` (override via `REALTRY_SETTINGS_PATH`, atomic `0600` writes). Commands: `/retry` (unconditional continuation or immediate backoff wake) and `/realtry` (`status`, `settings`, `reset`, `help`).
- Footer: During an active automatic retry cycle (`attempt > 0`, across backoff and in-flight retry turns) or active manual `/retry` turn, `RealtrySessionController.syncFooterStatus()` publishes `ui.setStatus("realtry", "🔁 <remaining>")`, ticking every 1s via an unref'd interval (`12h00m00s` / `9m58s` / `29s` / `∞`). It clears `ui.setStatus("realtry", undefined)` immediately on completion, cancellation, reset, or shutdown.
- Architecture:
  - `src/runtime.ts` hooks `AgentSession`: `_handlePostAgentRun`, `_prepareRetry`, `_willRetryAfterAgentEnd`, `abortRetry`, `_getSummarizationRequestAuth` (unwrapping `agent.streamFunction` to preserve #11520 OAuth summarization), and `agent.finishTurn` (returns `{ action: "end" }` on `stopReason === "length"` with `toolCall`s so `agent-loop`'s synthetic truncated-tool error `toolResult`s are omitted instead of sent to the model).
  - `src/stream-watchdog.ts` wraps `agent.streamFunction` with an inactivity timer (`stallTimeoutMs`) using a child `AbortController` (`AbortSignal.any`); stall aborts resolve as retryable `stopReason: "error"`, while real user Esc aborts remain `stopReason: "aborted"`.
  - `src/tail.ts` prepares sessions for `/retry` via durable `context_edit(targetId, null)` omissions: strips trailing `assistant` entries and rolls back interrupted/unpaired tool batches (`Operation aborted` or bash `Command aborted`), while preserving completed tool batches.
